# وب‌سایت شخصی عرفان شرفی

سایت تک‌صفحه‌ای، ساخته‌شده با **Next.js 15 (App Router)**، **TypeScript** و **Tailwind CSS v4**.
**بدون بک‌اند**: نه دیتابیسی در کار است، نه مسیر API، نه پنل مدیریت. همهٔ محتوا داخل فایل‌های
پروژه است و کل سایت هنگام بیلد به صفحه‌های استاتیک تبدیل می‌شود.

## چه چیزهایی دارد

- **صفحهٔ اصلی** — معرفی، درباره من، سوابق کاری، تحصیلات، نمونه‌کارها و بخش تماس.
- **فرم تماس بدون سرور** — فرم ورودی را در مرورگر اعتبارسنجی می‌کند و بعد همان متن آماده را
  در **ایمیل**، **واتس‌اپ** یا **تلگرام** خود کاربر باز می‌کند تا پیام مستقیم برسد. دکمهٔ
  «رونوشت متن پیام» هم به‌عنوان راه چهارم هست؛ اگر مرورگر اجازهٔ رونوشت خودکار ندهد، متن برای
  انتخاب دستی نشان داده می‌شود. (تلگرام اجازهٔ پر کردن متن گفت‌وگوی خصوصی از روی لینک را نمی‌دهد،
  پس متن رونوشت می‌شود و گفت‌وگو باز می‌شود تا فقط جای‌گذاری شود.)
- **راه‌های ارتباطی** — ایمیل، تلفن، واتس‌اپ، تلگرام، گیت‌هاب و لینکدین، هم در بخش تماس و هم در پانوشت.
- SEO: متادیتا، `sitemap.xml`، `robots.txt`، Open Graph و دادهٔ ساخت‌یافتهٔ JSON-LD.

## راه‌اندازی

```bash
npm install
npm run dev              # http://localhost:4321
```

تنها متغیر محیطی، اختیاری است:

| متغیر | توضیح |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | آدرس عمومی سایت، برای sitemap، متادیتا و تصویر OG |

## دستورها

| دستور | کار |
| --- | --- |
| `npm run dev` | اجرای محیط توسعه روی پورت ۴۳۲۱ |
| `npm run build` | ساخت نسخهٔ تولید (همهٔ مسیرها استاتیک) |
| `npm start` | اجرای نسخهٔ ساخته‌شده |
| `npm run typecheck` | بررسی تایپ‌ها بدون خروجی |

## ویرایش محتوا

| چه چیزی را می‌خواهی عوض کنی | کدام فایل |
| --- | --- |
| نام، عنوان شغلی، ایمیل، تلفن، واتس‌اپ، تلگرام، شبکه‌های اجتماعی | `src/lib/site.ts` → `site` |
| ترتیب و عنوان راه‌های ارتباطی | `src/lib/site.ts` → `contactChannels` |
| متن‌های «درباره من»، سوابق کاری، تحصیلات، موضوع‌های فرم تماس | `src/lib/site.ts` |
| نمونه‌کارها (افزودن، ویرایش، حذف) | `src/lib/projects.ts` |

نام کاربری تلگرام در `site.telegram` (بدون `@`) نگه‌داری می‌شود؛ اگر خالی بگذاری، هم لینک تلگرام و
هم دکمهٔ «ارسال با تلگرام» خودبه‌خود از سایت حذف می‌شوند.

## ساختار

```
src/
  app/
    (site)/              صفحه‌های عمومی — سربرگ و پانوشت مشترک
      page.tsx           صفحهٔ اصلی
    layout.tsx           چیدمان ریشه، فونت، متادیتا و تم
    globals.css          توکن‌های تم و استایل‌های مشترک
    robots.ts            robots.txt
    sitemap.ts           sitemap.xml
  components/            اجزای رابط کاربری
  lib/
    site.ts              اطلاعات شخصی، راه‌های ارتباطی و متن‌های ثابت
    projects.ts          دادهٔ استاتیک نمونه‌کارها
    queries.ts           خواندن و مرتب‌سازی نمونه‌کارها (بدون دیتابیس)
    validation.ts        اعتبارسنجی فرم تماس با zod (فقط سمت مرورگر)
```

## استقرار

چون چیزی سمت سرور اجرا نمی‌شود، سایت را می‌شود روی Vercel (بدون هیچ متغیر محیطی اجباری)
یا هر میزبان دیگری منتشر کرد. برای خروجی کاملاً استاتیک و میزبانی روی فضای ساده
(مثل GitHub Pages یا هاست اشتراکی)، در `next.config.ts` مقدار `output: 'export'` و
`images: { unoptimized: true }` را اضافه کن و بعد از `npm run build`، پوشهٔ `out/` را آپلود کن.
